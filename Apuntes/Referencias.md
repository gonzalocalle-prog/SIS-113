# Referencias

Enlaces de consulta y estudio complementario.

| Recurso | Descripción |
|---------|-------------|
| [Getting Started with Java](https://dev.java/learn/getting-started/) | Guía oficial de Oracle para dar los primeros pasos: instalar el JDK, escribir y ejecutar el primer programa en Java. |
| [Java Programming MOOC — University of Helsinki](https://java-programming.mooc.fi/) | Curso gratuito y completo de programación en Java (partes I y II), con teoría, ejercicios autocorregidos y proyectos. Muy recomendado para práctica autónoma. |
| [10 OOP Design Principles — Javarevisited](https://javarevisited.blogspot.com/2018/07/10-object-oriented-design-principles.html) | Artículo que resume 10 principios de diseño orientado a objetos (DRY, encapsular lo que cambia, SOLID, composición sobre herencia, etc.) con ejemplos. |
| [Learn Java — dev.java](https://dev.java/learn/) | Portal oficial de tutoriales de Java: desde fundamentos del lenguaje hasta POO, colecciones, streams y más. Referencia principal para profundizar cualquier tema. |
